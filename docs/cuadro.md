# Matriz de Diagnóstico, Operación y Continuidad

> **Leyenda de cobertura (columna 4):** 🟢 cubierto hoy con fuerza · 🟡 parcial (motor disponible, falta integración/documentación/arquitectura) · 🔴 próxima fase (no construido, pero alcanzable sobre la base actual). El patrón reutilizable que ya está vivo y certificado: **regla/Watcher → el agente correlaciona → propone playbook → aprobación L1 → AWX ejecuta → auditoría en `/historial`**. Cada dolor se resuelve instanciando ese patrón, no construyendo arquitectura nueva.
